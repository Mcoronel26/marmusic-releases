# mArmusic — Instaladores

Descargas oficiales de **mArmusic**. Cada versión está en [Releases](../../releases).

- **Android:** `mArmusic-X.Y.Z.apk`
- **Windows:** `mArmusic-Setup-X.Y.Z.exe` (próximamente)

La app avisa sola cuando hay una versión nueva y verifica la huella SHA-256 de cada archivo antes de instalarlo.

> El código fuente no está en este repositorio.
